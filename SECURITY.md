# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Ticket Tally seriously. If you believe you have found a security vulnerability, please follow these steps:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability directly to the project maintainers via GitHub private security advisories or repository maintainer contact.
3. Include details of the vulnerability, steps to reproduce, and any proof-of-concept code.

We will acknowledge your report promptly, investigate the issue, and release a fix as soon as possible.
